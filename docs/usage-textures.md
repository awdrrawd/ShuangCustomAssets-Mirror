# 贴图管理

自定义贴图可装备于各物品部位。每个道具有 18 个固定槽位，每页 6 个，共 3 页。

- 悬停槽位网址可查看当前姿势使用的图片缩图；点击网址可修改别名。
- 槽位后的操作按顺序排列：显示／隐藏、编辑、信任。空槽位的「添加」占第一个操作位置。
- 网址后的红色「!」表示图片已失效或加载失败；悬停查看说明。未信任或被屏蔽的图片不会被预览加载，也不会被误报为失效。
- 教程「?」在确认按钮左侧。教程的上一页、下一页和理解了按钮不显示重复的悬浮说明。
- 原教程位置的垃圾桶切换批量删除模式。开启后隐藏显示、编辑、信任与添加按钮，只在已使用槽位显示「删除」。逐个点击即可快速删除，再点垃圾桶退出模式。
- 删除保留中间空槽位，不改变后续槽位与优先级；同时清除被删除槽位的优先级。
- 上锁且没有解锁权限时，不能通过列表按钮修改或删除。

添加或编辑后按确认保存；取消会同时还原图片参数和图层优先级。顶部勾号保存并退出；隐藏设置按钮管理身体／服饰隐藏。

底部提供导出、覆盖导入与追加导入。追加会优先填补空槽位，数量超限时不会写入部分资料。

详情见[编辑面板](./usage-edit-panel.md)、[导入导出](./usage-import-export.md)与[保存及加载机制](./architecture.md)。
