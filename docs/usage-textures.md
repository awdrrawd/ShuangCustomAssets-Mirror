# 贴图管理基础

## 装备道具

「自定义贴图」注册在所有物品部位组中，可以在任意部位找到并装备。

装备后点击道具即可打开贴图管理面板。

## 图层列表

```
┌──────────────────────────────────────────────────────┐
│ 贴图管理                          [隐藏设置] [确认退出] │
│ 已添加 N 个贴图（最多 16 个）                          │
├──────────────────────────────────────────────────────┤
│ 图层1 : [url预览...]    [显示] [编辑] [信任]          │
│ 图层2 : [url预览...]    [隐藏] [编辑]                 │
│ ...                                                   │
│ [+]                                                    │
│                                                       │
│              [导出配置] [覆盖导入] [追加导入]          │
└──────────────────────────────────────────────────────┘
```

- 最多支持 **16 个图层**，每页显示 6 个，图层达到 7 个时显示「下一页」翻页按钮
- 每个图层独立显示/隐藏（绿色 = 显示，灰色 = 隐藏）
- 图层按顺序叠加渲染，序号越小越靠后（底层）

### 右上角图标按钮

- **隐藏设置**（盾牌图标）：进入隐藏设置页面，隐藏角色身体部位
- **确认并退出**（勾号图标）：保存并同步到服务器后关闭对话框

### 底部按钮

- **导出配置**：将当前配置复制到剪贴板
- **覆盖导入**：用剪贴板配置替换当前所有图层
- **追加导入**：将剪贴板配置追加到当前图层之后

## 添加新贴图

1. 点击「+」按钮（紧跟在当前页最后一个图层之后）
2. 自动进入图层编辑面板
3. 在编辑面板中配置贴图参数
4. 点击「确认」保存该图层

## 编辑图层

点击图层右侧的「编辑」按钮进入编辑面板，可调整该图层的所有参数。

详细操作请参考 [编辑面板详解](./usage-edit-panel.md)。

## 删除图层

在编辑面板中，点击右下角的垃圾桶图标即可删除当前图层。

## 显示/隐藏切换

每个图层可独立控制可见性：
- **绿色按钮「显示」**：该图层可见
- **灰色按钮「隐藏」**：该图层不渲染，但配置保留

> 切换可见性会立即同步到服务器并刷新角色，无需额外点击保存。

## 保存与同步

- **编辑图层时的参数调整**：仅本地预览，不同步服务器
- **点击「确认」返回列表**：保存到本地道具属性
- **点击右上角「确认并退出」**：将所有图层配置同步到服务器，其他玩家可见，并关闭对话框

> 如果直接关闭对话框而不点击「确认并退出」，服务器端不会更新，下次打开时恢复为上次保存的状态。

## 信任域名

如果图层使用了不在白名单中的域名，列表中会显示「信任」按钮。点击后会进入域名确认页面，查看风险提示后可将其添加到可信白名单。

详细说明请参考 [安全设置](./usage-security.md)。
