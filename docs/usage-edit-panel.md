# 编辑面板详解

进入图层编辑后，右侧面板显示所有可调参数。

## 面板布局

```
┌──────────────────────────────────────────┐
│ 编辑图层1                                 │
│ 修改后自动预览，点击「确认」返回列表        │
├──────────────────────────────────────────┤
│ 贴图  [_________URL_________] [信任]      │
│                                          │
│ [移动]                                   │
│                                          │
│ X偏移  [-] [___] [+]                      │
│ Y偏移  [-] [___] [+]                      │
│ 镜射   [水平] [垂直]                      │
│ 缩放%  [-] [___] [+]                      │
│ 旋转%  [-] [___] [+]                      │
│ 透明度% [-] [___] [+] [====滑桿====]      │
│ 图层优先级 [-] [___] [+]                   │
│                                          │
│ 当前姿势: 手臂下垂 + 站立  [独立配置: 关]  │
├──────────────────────────────────────────┤
│ [确认]  [删除]               (右上角)     │
└──────────────────────────────────────────┘
```

## 贴图 URL

输入图片的完整网址（需以 `https://` 开头）。

要求：
- 图片服务器需支持 CORS（跨域资源共享）
- 推荐图床：GitHub Pages、jsDelivr CDN、自建静态服务器
- 不支持 `http://`（非加密连接）

输入后自动预加载图片，加载完成后自动刷新预览。

## X偏移 / Y偏移

控制贴图相对于道具基准点的水平/垂直位移。

- 数值框支持直接输入和鼠标滚轮调整
- 两侧的 `[-]` `[+]` 按钮支持点击和**长按加速**
- 长按时间越长，步进速度越快

## 移动按钮

点击「移动」按钮开启拖拽模式：
- 开启后（绿色），在左侧角色预览区域**按住鼠标拖动**即可直接移动贴图
- 拖拽时 X偏移和 Y偏移会实时更新
- 再次点击「移动」按钮关闭拖拽模式

> 拖拽模式比手动输入偏移值更直观，适合初步定位。

## 镜射

两个切换按钮，点击即翻转：
- **水平**：以图片中心为轴水平翻转
- **垂直**：以图片中心为轴垂直翻转

绿色 = 启用翻转，白色 = 不翻转。两个方向可同时启用。

## 缩放%

控制贴图大小的百分比。100% = 原始尺寸。

- `[-]` `[+]` 按钮步进为 1
- 长按可加速

## 旋转%

控制贴图旋转角度（度）。

- `[-]` `[+]` 按钮步进为 1
- 正数 = 顺时针，负数 = 逆时针

## 透明度%

控制贴图不透明度（0-100）。

- `[-]` `[+]` 按钮步进为 1
- 右侧附带**滑桿**，可拖拽快速调节
- 0 = 完全透明（不可见），100 = 完全不透明

数值框和滑桿双向同步，任一调整都会更新另一个。

## 图层优先级

控制该图层在角色身上的渲染层级（-99 到 99）。

- 数值越小 = 越靠后（底层），越大 = 越靠前（顶层）
- 与 BC 原生 Layering 界面同步
- `[-]` `[+]` 按钮步进为 1

> 此设置独立于图层序号。图层序号决定编辑顺序，优先级决定渲染顺序。

## 确认与取消

- **确认**（右上角勾号）：保存当前图层配置并返回列表
- **删除**（右下角垃圾桶）：删除当前图层并返回列表
- **直接返回**（关闭对话框）：不保存本次编辑，恢复原始配置

> 编辑期间的参数调整仅用于本地预览。只有点击「确认」后才会写入道具属性，点击「确认保存」后才会同步到服务器。
