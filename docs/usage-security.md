# 安全设置

## 功能说明

自定义贴图需要从外部图床加载图片，为防止恶意图片加载，插件提供域名白名单管理功能。此外还提供动态图片（GIF 动图）播放开关与帧率调节，兼顾安全与性能。

扩展设置页面分为两块：

- **贴图加载安全**：白名单/不限制模式、域名管理、不可信域名提示
- **动态图片**：动图播放开关、帧率调节、与游戏帧率同步

## 安全模式

在扩展设置主页面点击「加载模式设置 >>>」可选择安全模式：

### 白名单模式（推荐）

- 仅允许白名单中的域名加载图片
- 非白名单域名的图片不加载、不渲染
- 新增域名时需手动添加到白名单

### 不限制模式

- 允许任意 HTTPS 域名的图片加载
- 不做域名检查
- 仅在你完全信任所有图床来源时使用
- 首次开启需经过隐私风险确认页面

## 域名白名单管理

在扩展设置主页面（白名单模式下）点击「域名白名单管理 >>>」进入管理页面。

### 添加域名

**方法一：从编辑面板添加**
1. 在贴图列表中，使用了非白名单域名的图层会显示「信任」按钮
2. 点击「信任」按钮
3. 在确认页面查看风险提示后点击「确认添加」

**方法二：手动添加**
1. 在白名单管理页面底部输入框中输入域名（如 `example.com`）
2. 点击「添加」按钮

**方法三：一键添加推荐域名**
1. 点击「添加推荐域名」按钮
2. 内置推荐图床域名（GitHub Pages、imgur、catbox、Discord CDN 等）会自动加入白名单
3. 已存在的域名不会重复添加

### 删除域名

1. 在白名单列表中找到要删除的域名
2. 点击该行右侧的「删除」按钮

### 清空全部

点击「清空全部」按钮，经二次确认后移除所有可信域名。

> ⚠ 清空后插件自身服务域名（`shuang-custom-assets.pages.dev`）仍始终允许，不影响内置资源加载。

### 翻页

白名单每页显示 8 条，支持「上一页 / 下一页」翻页。添加新域名后会自动跳转到最后一页。

## 不可信域名提示

在扩展设置主页面可切换「不可信域名提示」开关：

- **提示开启**：遇到非白名单域名时显示固定的警告图片，提醒该域名不可信
- **提示关闭**：直接跳过，不加载也不渲染该图片

## 动态图片设置

扩展设置主页面提供 GIF 动图相关开关（位于「不可信域名提示」下方）：

### 启用动态图片

- **开**（默认）：多帧 GIF 正常播放动画
- **关**：GIF 只显示第一帧，不播放动画，也不参与动图刷新计时器的轮询

> 关闭动态图片可降低 CPU 开销，适合低端设备或人多的房间。

### 动图帧率

直接在输入框中输入帧率数值（单位 fps，范围 **2~30**）：

- 数值越大播放越流畅，CPU 开销越大
- 数值越小越省 CPU，但动画会卡顿
- 默认 10 fps（100ms 间隔）

> 帧率为动画刷新间隔，与图片本身的实际帧率无关。即使图片是 30fps 的 GIF，设置为 10fps 也只按 10fps 刷新。

### 同步游戏帧率

勾选「同步游戏帧率: 开」后：

- 动图帧率自动跟随游戏设置中的 `MaxFPS`（`Player.GraphicsSettings.MaxFPS`）
- 帧率输入框禁用并显示当前游戏帧率值
- 游戏帧率设为 0（无限制）时按 60 fps 处理

> 取消勾选后恢复使用手动输入的帧率值。

## 白名单导入导出

### 导出

1. 在白名单管理页面点击「导出配置」
2. 白名单以 JSON 数组格式复制到剪贴板
3. 剪贴板不可用时自动降级为下载 JSON 文件

格式示例：
```json
["github.io", "imgur.com", "catbox.moe"]
```

### 导入

1. 将白名单 JSON 数组复制到剪贴板
2. 点击「导入配置」
3. 弹出输入框粘贴 JSON（格式如 `["domain1.com", "domain2.com"]`）
4. 确认后合并到现有白名单（已存在的域名不重复添加）

## 始终允许的域名

插件自身的服务域名（`shuang-custom-assets.pages.dev`）始终被允许，不受白名单限制。这确保了登录页标识和不可信域名警告图等内置资源始终能正常加载。

> 主源（Cloudflare Pages）加载失败时，会自动回退到备用源（Netlify）。

## 推荐图床

以下图床服务支持 CORS，可以正常加载：

| 图床 | 说明 |
|------|------|
| GitHub Pages | 免费，适合静态图片托管 |
| jsDelivr CDN | 免费，可加速 GitHub 仓库中的图片 |
| Cloudflare Pages | 免费，支持自定义域名 |
| Netlify | 免费，支持静态托管 |
| imgur / imgbb / imgchest | 公共图床，支持 CORS |
| catbox / litterbox | catbox.moe 永久存储，litterbox 临时存储 |
| Discord CDN | 返回 CORS 头，但附件链接带过期参数，仅适合临时使用 |
| Cloudflare R2 | 需在存储桶配置 CORS 响应头 `Access-Control-Allow-Origin: *` |
| 自建服务器 | 需配置 CORS 响应头 `Access-Control-Allow-Origin: *` |

> 不支持 CORS 的图床（如部分国内图床）会导致图片加载后被浏览器拒绝渲染到 canvas。
