# 隐藏设置

## 功能说明

隐藏设置允许你隐藏角色身上的特定部位组，让自定义贴图不被身体模型、服饰或拘束道具遮挡。

## 分类说明

共 8 个分类，每个分类可独立开关：

| 分类 | 说明 | 包含的部位 |
|------|------|-----------|
| 表情图标 | 角色的表情符号 | Emoticon |
| cosplay | 角色扮演相关部位 | 前发、后发、翅膀、尾巴、动物身体、额外身高等 |
| 五官 | 面部特征 | 眼睛、眉毛、腮红、眼影、面部毛发、嘴巴等 |
| 头部 | 头部模型 | Head |
| 上半身 | 上半身躯干与手臂 | 上身、乳头、左/右手臂、左/右手 |
| 下半身 | 下半身躯干及整体身高 | 下身、阴部、身高、身体样式、代词、外观工具 |
| 服饰 | 服装和饰品 | 衣服、下装、外套、胸罩、内裤、套装、袜子、鞋子、手套、饰品等 |
| 拘束道具 | 所有拘束物品 | ItemAddon、ItemArms、ItemBoots 等全部 Item 组 |

> 旧版本的「身体」分类已拆分为「头部」「上半身」「下半身」三个。导入旧配置或加载旧道具时，原来的 `HideBody=true` 会自动迁移为这三个分类全部开启。

## 贴图异常保护

页面顶部的「贴图异常保护」开关（默认关闭）决定贴图显示异常时还要不要隐藏原服装：

- 开启后，只要有任何一张应当显示的贴图尚未加载完成、加载失败、域名不在白名单/被判定为不可信，或来源玩家被屏蔽，就不写入 `Property.Hide`，游戏原本的身体与服饰照常显示。
- 所有贴图都成功显示后，所选分类的隐藏才会生效；贴图异步加载完成、失败或信任状态变化时会自动重算并刷新角色。
- 没有配置任何可显示贴图时没有需要等待的对象，隐藏照常生效。
- 该开关属于道具属性（`HideOnlyWhenReady`），会随道具同步和导出导入；但「贴图是否正常显示」由每位玩家自己的网络、白名单与屏蔽设置判断，因此不同玩家看到的隐藏状态可能不同。

> 典型用法：用贴图制作衣服并隐藏游戏原服装。开启保护后，如果图片服务器失效、域名未被信任或被屏蔽，角色仍会保留原服装，而不会出现「衣服被隐藏、贴图又没显示」的情况。

## 详细调整

每个分类行右侧都有「详细调整」按钮，点进去逐组控制该分类；页内仍可切换其他分类：

- 列表显示该分类下的全部部位组（例如 `Cloth`、`Bra`、`Panties`），每组可单独设为显示/隐藏。
- 逐组设置会覆盖分类开关：分类开启时可单独放行某些组，分类关闭时可单独隐藏某些组；未单独设置的组继续跟随分类。
- 修改先在本机预览，不发送服务器；点击右上角「确认并同步」才一次性上传，只会触发一次编辑广播。
- 点击右上角返回箭头或直接退出会放弃本次修改，并还原进入前的逐组设置。
- 鼠标移到某个部位组上，会显示该角色该部位正在使用的物品名（例如「正在使用：头发12」）；名称优先使用游戏本地化描述。
- 没有穿戴物品的部位用灰色显示，并在组名后标注「无」；悬停时也只显示「无」，方便快速定位空位。
- 分类存在逐组例外时，外层的显示/隐藏按钮会变成橙色的「部分」；点击仍然切换整个分类。
- 每页 16 个组，底部可翻页；「清除本分类覆盖」会删除当前分类的所有逐组例外。

> 逐组结果保存在道具属性 `HideOverrides`，随道具和导出配置一起保存；`Property.Hide` 仍由分类开关、逐组覆盖和贴图异常保护共同计算。

## 使用方法

1. 在贴图管理列表页，点击「隐藏设置」按钮
2. 进入隐藏设置页面，顶部为「贴图异常保护」开关，下方为 8 个分类开关
3. 点击开关切换显示/隐藏（绿色 = 显示，灰色 = 隐藏）；需要更精确时点击该分类行右侧的「详细调整」
4. 点击右上角勾号按钮「确认并返回列表」
5. 在列表页点击右上角勾号「确认并退出」同步到服务器

> 隐藏设置会写入道具的 `Property.Hide` 数组，BC 会根据该数组隐藏对应部位的图层。其他玩家也会按自己的贴图加载结果应用隐藏效果。

## 使用场景

### 贴图被身体遮挡

如果你的贴图定位在身体上但被衣服或身体模型遮挡：
1. 开启「上半身」和「下半身」隐藏（必要时也开启「头部」）
2. 开启「服饰」隐藏
3. 贴图将显示在最上层

### 替换身体外观

用贴图完全替换角色外观时：
1. 开启「头部」「上半身」「下半身」隐藏（隐藏原始身体模型）
2. 开启「五官」隐藏（隐藏原始面部）
3. 开启「cosplay」隐藏（隐藏发型、翅膀等）
4. 贴图成为角色的唯一外观

### 仅隐藏部分部位

如果只需要隐藏特定类别（如只隐藏衣服但保留身体）：
1. 只开启「服饰」隐藏
2. 身体各部位保持显示
