# 隐藏设置

## 功能说明

隐藏设置允许你隐藏角色身上的特定部位组，让自定义贴图不被身体模型、服饰或拘束道具遮挡。

## 分类说明

共 8 个分类，每个分类可独立开关：

| 分类 | 说明 | 包含的部位 |
|------|------|-----------|
| 表情图标 | 角色的表情符号 | Emoticon |
| cosplay | 角色扮演相关部位 | 前发、后发、翅膀、尾巴、动物身体、额外身高等 |
| 五官 | 面部特征 | 眼睛、眉毛、腮红、眼影、面部毛发、嘴巴等 |
| 头部 | 头部模型 | Head |
| 上半身 | 上半身躯干与手臂 | 上身、乳头、左/右手臂、左/右手 |
| 下半身 | 下半身躯干及整体身高 | 下身、阴部、身高、身体样式、代词、外观工具 |
| 服饰 | 服装和饰品 | 衣服、下装、外套、胸罩、内裤、套装、袜子、鞋子、手套、饰品等 |
| 拘束道具 | 所有拘束物品 | ItemAddon、ItemArms、ItemBoots 等全部 Item 组 |

> 旧版本的「身体」分类已拆分为「头部」「上半身」「下半身」三个。导入旧配置或加载旧道具时，原来的 `HideBody=true` 会自动迁移为这三个分类全部开启。

## 使用方法

1. 在贴图管理列表页，点击「隐藏设置」按钮
2. 进入隐藏设置页面，显示 8 个分类开关
3. 点击开关切换显示/隐藏（绿色 = 显示，灰色 = 隐藏）
4. 点击右上角勾号按钮「确认并返回列表」
5. 在列表页点击右上角勾号「确认并退出」同步到服务器

> 隐藏设置会写入道具的 `Property.Hide` 数组，BC 会根据该数组隐藏对应部位的图层。其他玩家也能看到隐藏效果。

## 使用场景

### 贴图被身体遮挡

如果你的贴图定位在身体上但被衣服或身体模型遮挡：
1. 开启「上半身」和「下半身」隐藏（必要时也开启「头部」）
2. 开启「服饰」隐藏
3. 贴图将显示在最上层

### 替换身体外观

用贴图完全替换角色外观时：
1. 开启「头部」「上半身」「下半身」隐藏（隐藏原始身体模型）
2. 开启「五官」隐藏（隐藏原始面部）
3. 开启「cosplay」隐藏（隐藏发型、翅膀等）
4. 贴图成为角色的唯一外观

### 仅隐藏部分部位

如果只需要隐藏特定类别（如只隐藏衣服但保留身体）：
1. 只开启「服饰」隐藏
2. 身体各部位保持显示
