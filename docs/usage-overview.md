# 使用教程总览

霜自定义道具（ShuangCustomAssets）是一款 Bondage Club 游戏插件，让玩家通过图床链接实现动态贴图效果。

## 功能一览

| 功能 | 说明 | 教程 |
|------|------|------|
| 贴图管理 | 添加、编辑、删除图层，最多 18 层 | [贴图管理基础](./usage-textures.md) |
| 编辑面板 | 调整偏移、缩放、旋转、透明度、镜射等参数 | [编辑面板详解](./usage-edit-panel.md) |
| 姿势独立配置 | 为不同姿势设置不同的贴图参数 | [姿势独立配置](./usage-pose-settings.md) |
| 隐藏设置 | 隐藏角色的头部、身体、服饰、道具等部位（8 个分类） | [隐藏设置](./usage-hide-settings.md) |
| 导入导出 | JSON 配置的导出、分享和导入 | [导入导出](./usage-import-export.md) |
| 安全设置 | 域名白名单管理，防止恶意图片加载 | [安全设置](./usage-security.md) |
| 动图播放 | GIF 动图开关、帧率调节、同步游戏帧率 | [安全设置](./usage-security.md#动态图片设置) |

## 快速上手

1. 在任意部位物品栏找到「自定义贴图」并装备
2. 点击道具打开编辑面板
3. 点击「添加新贴图」创建第一个图层
4. 输入图床 URL（需以 `https://` 开头，且支持 CORS）
5. 调整偏移、缩放等参数，实时预览效果
6. 点击「确认」返回列表
7. 点击「确认保存」同步到服务器

> 详细的操作说明请查阅上方各功能教程。
