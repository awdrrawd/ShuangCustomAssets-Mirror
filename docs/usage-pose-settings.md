# 姿势独立配置

## 功能说明

角色在游戏中有不同的姿势（手臂、腿部、全身），不同姿势下贴图可能需要不同的位置和参数。

姿势独立配置允许你为每个姿势组合设置不同的贴图参数。未配置的姿势使用全局配置（即编辑面板中默认的参数）。

## 姿势分类

| 类别 | 姿势（UI 中文标签） | 数量 |
|------|------|------|
| 手部姿势 | 基础手势、举手、高举双手、轻松背手、紧绷背手、背后手铐 | 6 种 |
| 腿部姿势 | 站立、跪姿、跪地张腿、站立闭合、站立张腿 | 5 种 |
| 全身姿势 | 仰卧、四肢着地 | 2 种，覆盖手部+腿部 |

手部姿势和腿部姿势可以两两组合（如「举手 + 跪姿」），全身姿势会覆盖手部和腿部。

> 姿势名称以游戏内编辑面板底部「当前姿势」栏显示的中文标签为准。

## 界面说明

编辑面板底部显示当前姿势信息和独立配置开关：

```
当前姿势: 举手 + 跪姿    [独立配置: 关]
```

- **当前姿势**：实时显示角色当前的姿势组合
- **独立配置开关**：点击切换该姿势的独立配置

## 使用流程

### 开启独立配置

1. 将角色切换到目标姿势（如「举手 + 跪姿」）
2. 界面底部显示「当前姿势: 举手 + 跪姿」
3. 点击「独立配置: 关」按钮，变为「独立配置: 开」（绿色）
4. 此时编辑面板中的所有参数（URL、偏移、缩放等）切换为该姿势的独立配置
5. 首次开启时，所有参数从全局配置继承（与全局相同）
6. 修改需要的参数，实时预览效果

### 切换姿势

在独立配置开启状态下切换角色姿势：
- 编辑面板**自动跟随**到新姿势
- 如果新姿势已有独立配置：加载该姿势的配置
- 如果新姿势没有独立配置：切回全局配置模式（之前姿势的配置保留不丢失）
- 可以为新姿势单独开启独立配置

### 关闭独立配置

点击「独立配置: 开」按钮即可关闭：
- 该姿势的独立配置被删除
- 编辑面板切回全局配置

### 保存

点击编辑面板右上角的「确认」（勾号）按钮：
- **同时保存**全局配置和所有已开启的姿势独立配置
- 所有配置在此刻统一写入道具属性
- 需要在列表页点击「确认保存」才会同步到服务器

### 取消

直接返回（不点击确认）：
- **所有修改撤回**，包括全局配置和所有姿势配置
- 恢复为进入编辑前的原始状态

## 常见场景

### 场景1：不同姿势用不同图片

```
全局配置: default.png, OffsetX=1, OffsetY=1
举手+跪姿: yoked_kneel.png, OffsetX=15, OffsetY=-30
仰卧: hogtied.png, Rotation=90
```

1. 在全局配置中设置默认图片和参数
2. 切换到「举手 + 跪姿」姿势
3. 开启独立配置，修改 URL 和偏移
4. 切换到「仰卧」姿势
5. 开启独立配置，修改 URL 和旋转
6. 点击「确认」保存所有配置

### 场景2：某姿势下隐藏贴图

```
全局配置: Visible=true
四肢着地: Visible=false
```

1. 切换到「四肢着地」姿势
2. 开启独立配置
3. 将「可见」设为关闭（在列表页操作）
4. 点击「确认」保存

### 场景3：仅调整偏移

```
全局配置: OffsetX=1, OffsetY=1
跪姿: OffsetY=-30（其他参数不变，自动继承全局）
```

1. 切换到「跪姿」姿势
2. 开启独立配置（所有参数从全局继承）
3. 只修改 Y 偏移
4. 点击「确认」保存

> 即使只改了一个参数，独立配置会保存所有字段的值。渲染时以独立配置为准。
